Before we begin

先说明白：你的东西放在哪里

这个小店完全跑在这台电脑上。没有账号，也没有云端同步。安装包是干净的，不会带任何人的聊天或 Key。

✦
聊天与 API Key

保存在 %APPDATA%\liven-pet，只属于当前 Windows 用户。

❧
她写下的作品

默认放在 文档\Eternity coffee\作品，你可以随时改。

◎
分享软件时

只分享安装包。不要把数据目录或整个程序目录压缩给别人。

勾选后继续

Optional · Language model

要不要现在接通模型？

接通后，Liven 才能自己写新稿、读书感想和连载。没有 Key 也能用：她会用本地台词陪你，书架和作品库也照常。
